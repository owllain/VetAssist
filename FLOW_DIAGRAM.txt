┌─────────────────────────────────────────────────────────────────────────────┐
│                    FLUJO INTERNO DE DATOS                                   │
└─────────────────────────────────────────────────────────────────────────────┘

INPUT USUARIO
     ↓
     ├─ petType: 'perro' | 'gato'
     ├─ weight: número > 0
     ├─ BCS: 1-9
     ├─ criterios: edad/condición específica
     ├─ mealsPerDay: 1-6
     └─ foodMode: 'manual' | 'catalog'
                   ↓
                   └─ Si catalog: brand + producto
                   └─ Si manual: unidad + kcal/unidad
     
     ↓ VALIDACIÓN
     
     CÁLCULOS (food-data.ts)
     ├─ RER = 70 × (weight)^0.75
     ├─ multiplier = getMERMultiplier(species, criteria)
     ├─ MER = RER × multiplier
     ├─ water = MER × 1
     ├─ kcalPerMeal = MER / mealsPerDay
     └─ portions = FOOD_CATALOG lookup + conversión
     
     ↓ BUSCAR DATOS
     
     ACCESO A DATOS
     ├─ food-catalog.ts → FOOD_CATALOG[]
     ├─ bcs-levels.ts → getBCSLevel(species, score)
     └─ food-data.ts → getFoodPortions()
     
     ↓ FORMATEO
     
     GENERACIÓN DE RESULTADOS
     ├─ Texto de resultados
     ├─ Sugerencias de comidas
     ├─ Información nutricional
     └─ Recomendaciones clínicas
     
     ↓
     
     PRESENTACIÓN UI
     └─ Tarjetas de colores (RER/MER/agua)
        Tablas de porciones
        Botón copiar resultados
